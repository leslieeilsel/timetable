# 长期调课

长期调课从指定日期起改变按周执行的固定安排。教务直接修改、检查、确认发布，不设申请和审批；老师消息是否已读不影响生效。

## 操作路径

- 首页显示调整记录、具体变化、生效时间和状态，搜索在服务端分页前执行；日期筛选采用区间交集。已有基础课表区间仍可从“课表生效时间线”查看。
- 与临时调课共用页面骨架：调整记录 → 选择课程 → 设置新安排 → 核对发布。紧凑的横向步骤导航区分已完成、当前和后续步骤，不重复显示大标题和步骤卡片。页头、记录筛选、课程搜索、原课程摘要、调整方式、目标课程列表、前后对照和底部按钮复用同一套组件。
- “新建调课”直接输入老师、班级或教室名称，支持拼音全拼、首字母和教师工号；无需先选择对象类型。“按分类选”保留已有选择器。默认从下周一开始，至学期结束，支持指定结束日期。
- 默认按任课关系归组，显示任课数量和每组固定课节数；可直接整组换老师或教室，也可展开选择单节。对象和课程筛选用于定位任课，整组始终包含该任课的全部课节，不会被教室等筛选暗中缩小范围。单双周沿用各课节原规则，含锁定课节的整组禁用。
- 操作顺序保持“换课、改时间、换老师、换教室”。整组选择换课或改时间时，先明确要改变的固定课节。更换老师替换主讲，协同教师继续保留。
- 已确定的调整直接录入，不提供三个推荐方案。换课选择目标星期和课节，再点击对应课程；改时间直接指定新的星期和课节。目标班级默认原课所属班，可使用现有班级选择器明确切换，合班课程按成员班级匹配；也可选择“查看当天全部课节”。课程按课节顺序显示，冲突原因标在对应行。
- 课程搜索和课程筛选位于选课列表上方；目标课程可独立搜索。教师和教室复用现有选择器，提前禁用与选中课时冲突的资源。整个生效期间的硬规则由“下一步：核对”验证，再由操作者“确认发布”。
- 编辑页使用一个工作面板：左侧原课程摘要始终显示修改前的安排及生效区间，右侧集中显示调整方式、目标安排和原因。“查看周课表”作为目标安排旁的弱入口保留，原课程栏不再放课表按钮。完成选择后显示“新安排已设置，尚未发布”及简短摘要，累计操作可按需展开，完整前后对照集中在核对页。恢复草稿或从核对页返回时继续显示已设置状态，可继续修改、调整其他课程或撤销这步。
- 修改按操作分组，可逐组撤销。草稿只保存在当前浏览器、当前用户和学期，继续草稿时校验课程是否变化；全部撤销后清理本方案草稿。已有草稿时开始新方案会提示替换规则。
- 确认页列出课程在各日期区间的前后安排，以及阶段性调整结束后紧接着执行的安排。发布后老师按日期读取实际课表，可选择生成涉及老师的个人站内消息。
- 从预览返回修改或重新打开草稿时，保留选中的课程、调整方式及整组范围。草稿用稳定的课节标识恢复选择，兼容此前未保存选择信息的草稿；预览计算期间禁用编辑，避免表单与核对结果不一致。
- 未生效的调整可以取消；已生效的调整可以选择从今天或未来某日起恢复。恢复同样先检查再确认，保留过去的实际安排及其他独立修改。

## 数据规则

新增 `/long-term-changes` 工作流，不更改旧的整份课表发布接口。`long_term_changes` 保存调整事项、搜索文本、每个生效区间的原始字段与调整后字段；内部自动创建对应版本，用户无需管理版本。

修改以稳定的 `entry_key` 定位课程，按现有生效区间分段，只应用本次变更字段。若未来同一字段已被其他安排修改，则阻止发布并给出具体日期，避免覆盖。每个新版本检查完整课时、资源资格、同步规则、固定安排和硬约束。冻结课程不能直接修改。原正式版本和未修改区间保持不变。

同一任课关系内的课节也支持互换。修改集中写入尚未发布的新版本，避免交换中间状态触发重复位置约束；稳定课程标识、班级及协同教师关系继续保留。

已有临时调课和代课在同一事务内重绑定，并在全部区间安装完毕后重新检查实际课表，包括跨区间交换的另一端和教师请假。更改星期若会导致已有临时调整或代课的原课不再存在，则阻止发布，要求先处理对应记录。恢复时应用相反字段修改，若已有后续修改依赖同一项安排，则阻止恢复；不会直接回退整份课表。

预览执行完整模拟并回滚，包括版本、区间、记录、消息和版本标记。发布及恢复在事务内重新验证，使用 `If-Match` 防止并发覆盖；消息写入与调整一同提交。新流程不允许追溯修改今天之前的安排。
