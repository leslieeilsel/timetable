# 排课入口与页面职责

- 日期：2026-09-23
- 范围：[改进计划](../requirements/scheduling_workflow_improvement_plan.md)的批次 A
- 状态：已实现；自动生成工作台、版本发布统一等批次 B–E 仍待实施

## 菜单与路由

“学期排课”改为可展开的菜单，管理员和排课员可直接打开以下页面。准备卡片、菜单、面包屑和浏览器标题采用同一名称。

| 页面 | 学期内路由 | 职责 |
| --- | --- | --- |
| 排课准备 | `/semesters/:semesterId/preparation` | 汇总准备状态与功能入口 |
| 班级与作息 | `/semesters/:semesterId/setup` | 维护本学期班级与作息 |
| 任课与课时 | `/semesters/:semesterId/assignments` | 维护任课、教师和周课时 |
| 排课规则 | `/semesters/:semesterId/constraints` | 维护硬约束和排课偏好 |
| 固定安排 | `/semesters/:semesterId/fixed-placements` | 维护必须固定的课程位置 |
| 编排课表 | `/semesters/:semesterId/planning` | 打开已有编辑、检查和发布能力 |

原四步编号导航已移除。侧栏收起时仍能通过菜单访问子页面；进入相关页面时展开对应分组。查看权限和各路由原有授权保持不变。“调课与代课”本轮沿用现有入口和页面内切换。

“班级与作息”作为独立排课页面，不再显示旧的“返回学年详情”。学年详情中的同目标快捷入口也统一命名为“班级与作息”，避免与学年、学期本身的管理混淆。

固定安排复用原列表、编辑器、接口和权限，改用独立路由，不再与规则列表互为页签。兼容入口如下：

- `/scheduling/fixed-placements` 解析到正在操作的学期。
- `/semesters/:semesterId/constraints?tab=fixed` 跳转到同学期的固定安排页面，删除 `tab`，保留其他查询参数和哈希。
- `/scheduling/constraints?tab=fixed` 经过原学期解析后同样兼容跳转。
- 服务端准备检查的固定安排 `fix_path` 更新为新入口，没有新增业务接口或数据迁移。

## 准备总览

原来混合统计与功能的卡片归为四张真实入口：班级与作息、任课与课时、排课规则、固定安排。卡片主体进入完整维护页，异常入口另行定位对应问题。

- 班级、工作日、可排课节归入班级与作息。
- 任课资源异常、课时容量问题归入任课与课时。
- 规则完整性与偏好提醒归入排课规则。
- 零条固定安排显示“未设置固定安排 / 可选”，不新增阻塞要求。
- 当前课表不再作为准备卡片；有正式课表时提供“查看已发布课表”。
- 存在草稿时，“继续编排”带入草稿版本；否则显示“进入编排”。该按钮仅导航，不创建生成任务。
- “重新检查”直接读取最新结果，移除二次确认与人为等待。失败时保留旧数据并标为待复核，不继续展示成功状态。
- 班级、作息、任课、规则、固定安排保存后使对应准备检查缓存失效，返回准备页时重新获取。

原 `/assignments?filter=issues` 和 `?filter=capacity` 只有链接参数，任课页面没有消费它们。本轮补上对应问题区：资源异常显示原因，容量问题按班级、教师或教室展示缺口并可展开相关任课；“编辑任课”复用现有编辑弹窗。“收起问题”保留列表的其他筛选和哈希。

## 编排入口

编排页提供“自动排课”入口；生成页提供“返回编排课表”，侧栏归属编排课表。当前自动排课仍使用 `/generate` 独立页面，其配置、任务、候选和采用逻辑保持原有实现。后续批次 B 再整合为围绕同一草稿的工作台。

允许从准备页进入编排查看与修复。实际生成、采用、发布继续使用各自服务端条件；本轮不修改求解器、候选采用条件或发布生效规则。
