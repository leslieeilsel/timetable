# 学科配色

- 课程持久化保存 `color`；名称、学期、班级及查看视角变化均不重新计算颜色。
- 色板统一定义于 `contracts/course-colors.json`。现有课程迁移时一次分配，启用课程优先。新建课程在目录写入锁内优先选择全校启用课程未占用的颜色，全部占用后选择使用次数最少的颜色。
- 基础资料 → 课程提供颜色列和编辑预览，支持手动选择、自动推荐及同色课程提示。允许显式同色；色板有限，不承诺任意数量的课程均不重色。
- 班级、年级、教师、教室及候选方案预览复用课程颜色；不提供学科图例或学科高亮筛选。年级视图保留教师高亮，打印时恢复全部课程正常显示。
- 冲突使用独立图标和文字提示，保留学科底色；标准周视图不合并临时调课，原有调课状态展示保持独立。
- 仅修改颜色递增 `app_settings.appearance_revision`，目录 ETag 携带该修订；不递增排课使用的 `catalog_revision` 或学期输入修订。颜色和业务字段一起修改仍按业务资料变更处理。
- CSV 不包含颜色。此变更不新增 Excel 文件配色功能。
