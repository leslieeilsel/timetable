# 年级课表总览功能说明

## 入口与范围

- 从课表页的「年级」页签进入，也支持 `view=grade` 查询参数。
- 使用当前学期及共用的课表版本选择器；年级列表来自本学期启用的班级配置，仅显示启用班级。
- 沿用现有课表访问与版本权限，不新增年级专属权限角色；年级总览提供查看、检查与导出。

## 查看与定位

- 按星期查看所选单日的全年级课表，保留课程全名、教师及课节时间。
- 桌面以班级为行、课节为列，班级列固定并收窄，班级名与进入箭头同行；窄屏在每天内按班级纵向展示。
- 支持选择年级，并切换「正式课程／完整作息」；切换年级时清除教师高亮及问题班级筛选。
- 教师高亮保留所有课程，将不匹配项淡化，并识别协同授课教师。不提供学科图例或课程高亮筛选。
- 展示标准周课表，保留单周、双周与指定周标注；不合并临时调课、代课，不代表某个日期的实际安排。
- 空白课格只表示未安排课程，不直接认定为漏排；合班课程显示在各参与班级中。

## 问题与计数

- 「只看有问题的班级」依据后端校验中的未完成任课任务与硬冲突，仅在校验成功且任课资料就绪时启用。
- 待排节数累计相关任课任务的 `max(0, required - scheduled)`；顶部分别统计待排节数大于零、有硬冲突的班级数。
- 冲突按课程记录、关联记录或任课任务归属班级；无归属标识的全局硬冲突对各班提示。
- 任课或规则资料已变化的旧版本仅作为只读历史快照，不展示可信的进度、冲突计数或问题筛选结果。
- 校验或任课资料不可用时明确显示状态，不将未知结果显示为零；校验失败可重试。

## 详情、返回与导出

- 点击课程打开居中弹窗，展示班级、教师、教室、课节时间、周次、版本、锁定状态及可用的关联冲突信息。
- 点击班级名或弹窗「查看该班周课表」进入班级视图；「返回该年级总览」保留总览选择与筛选状态。
- CSV 导出当前所选单日的全年级总表，包含版本、作息口径、课程、教师、教室与周次；历史快照注明待复核。
- Excel 压缩包导出本年级各班的整周 `.xlsx`，使用当前版本与作息口径；超过 200 个班时禁用此项。
- 两种导出均覆盖所选年级全部启用班级，不因高亮或问题班级筛选缩小范围。

## 视觉边界

- 沿用既有石墨中性色界面、浅色课程配色及现有控件；本功能不扩展全项目视觉规范，不修改 `DESIGN.md` 或 `PRODUCT.md`。
