# 校内排课员

## 用户画像

负责单校区小学或初中的日常排课。熟悉教师、班级、课程、教室和课务规则，但不应被迫理解接口、数据模型或系统内部术语。

## 目标

- 快速判断当前学期是否已经具备排课条件。
- 完成任课关系、规则和固定安排后生成可比较的候选方案。
- 在课表中定位冲突、调整安排并清楚知道修改是否已保存。
- 处理临时调课、请假和代课，不遗漏对班级、教师或教室的影响。

## 约束

- 主要在 13–16 英寸笔记本上工作，偶尔使用平板或手机查看状态。
- 开学前时间压力大，常在多个资料页与排课步骤之间来回切换。
- 能理解教务术语，但需要界面明确说明当前状态、下一步和动作后果。
- 高频任务应能凭清晰的视觉层次与一致的组件快速完成。

## 痛点触发器

- 页面只展示数据，不说明是否已经准备好或下一步该做什么。
- 保存、生成、发布或调整后缺少明确反馈。
- 表格、抽屉和侧栏在窄屏或中等宽度下相互挤压。
- 相同动作在不同页面使用不同标签、位置或交互方式。
- 加载、空、错误、禁用等状态看起来像页面损坏。

## 成功信号

- 进入工作台后，数秒内能判断当前学期状态与优先任务。
- 每个排课阶段都有清晰入口、完成状态和下一步建议。
- 关键修改具有即时反馈，返回上一级时数据同步更新。
- 桌面与移动端都能可靠完成核心流程，键盘焦点清晰。

## 审计方式

- 先快速扫视两秒，再阅读细节，记录所有需要停下来猜测的地方。
- 从工作台进入每条核心流程，不从深层链接直接开始。
- 对每个主要表单输入真实格式的中文、标点和边界数据。
- 在完成动作后验证网络、控制台、可见反馈与返回路径。
- 每个页面额外使用首次使用者视角，检查是否依赖内部知识。
