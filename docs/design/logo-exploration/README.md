# Logo SVG 探索

本目录只用于 Logo 造型选择，尚未替换系统当前品牌资源。

- `01-pai-wordmark.svg`：从“排”字抽取的定制字形，中文语义最直接。
- `02-timetable-t.svg`：三个课节组成的抽象 `T`，轮廓最简洁。
- `03-day-route.svg`：课表容器与编排路径的组合，业务含义最完整；当前选定方向。
- `comparison.svg`：三组方案在 16、24、32、64px、品牌组合与侧栏场景中的对比。
- `comparison.png`：便于直接预览的渲染图。

选择方向后再进行字重、负形、颜色与深浅背景适配，并输出生产用 SVG、favicon 和应用图标。
